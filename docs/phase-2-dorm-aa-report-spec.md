- 已有：3 个底部入口（岛屿 / 图鉴 / 宿舍岛占位）、记账、月预算 1500 + 存钱目标 300、岛血 100、消费怪物动画、许愿池（手动标记“计划购买”，24 小时冷静）、月结蛋 + 3 天孵化 + 演示快进、32 只精灵图鉴（普通 18 / 稀有 10 / 隐藏 4）、3D 岛屿与昼夜/音效/金币特效、JSON 备份导出与导入、Vitest 规则测试。
- 已有但仍是 v1 口径：预算按月设置、蛋按月结算、孵化 3 天；v2 的日/周预算、7 天蛋、日报、周报都还没做。
- 未做：分类统计、日报、周报、CSV 导入/导出、改/删账单、搜索筛选、种子数据接入、7 天孵化期、塔防小游戏、家园种地。
- Phase 2 四项（宿舍岛、AA、投票、年报）均未开始；许愿池已完成，不再重复开发。
- 结论：现在不应启动 Phase 2。先把 v2 §11 的基础功能做完整，否则宿舍岛做完也要跟着 v2 的报告和预算模型返工。

## 2. 优先级（以 v2 为准）

1. 记账：3 秒一键记、常用模板、改/删一笔、刷新不丢
2. 分类统计：8 个分类，日/周/月占比和总额
3. 日报：点“生成今日总结”出一份
4. 周报：点“生成周总结”出一份，可下载 / 复制
5. 7 天蛋：每日加分、周结算、档位、孵化
6. 塔防小游戏（可选）
7. 家园与种地（可选）
8. Phase 2：宿舍岛 + AA + 投票 + 年报

比赛截止 2026-11-30 18:00。如果时间不够，优先保证 1-5 能独立跑通，Phase 2 和塔防都可以不做。

## 3. 功能范围（后置，不删除）

### 3.1 宿舍岛（第 3 个 Tab，当前为占位）

- 4 人合建一座岛：成员用中性代称（你 / 室友 A / 室友 B / 室友 C），不编造真实姓名。
- 合建岛可视化：公共区域随宿舍共同结余变亮/长树，与个人岛同画风。
- 成员贡献条：每人本月记账天数、精灵数、对宿舍岛的贡献，不按“谁花得最少”排名。
- 岛规（宿舍公约变岛规）：可编辑 3 条，预置如“超预算的人请全宿舍喝奶茶”“拼单先记账再点单”“月底最后一天一起结算”。

### 3.2 AA 分账 + 月底一键结算

- 新增共享账单：金额、类别、付款人、参与人（默认 4 人，可勾选）、备注。
- 自动均分（可改自定义分摊），实时算出“谁欠谁”清单。
- 月底一键结算：生成结算单（A 应付 B ×× 元……），点“已结清”后清零并记一笔岛上事件。
- 种子数据：预置 8-10 笔 11 月真实感共享账单，详见 [`DATA-PLAN.md`](./DATA-PLAN.md)。

### 3.3 约饭投票

- 发起投票：吃什么 / 几点 / 去哪，选项 3-4 个，带截止时间。
- 4 人投票后出结果，得票最高的变成岛上事件；未投票显示“还差 X 人”。
- 种子数据：预置 1 个进行中的投票和 1 个已结束的。

### 3.4 年报分享卡

- 一键生成“我的 X 月岛屿年报”卡片：精灵数量（x/32）、岛亮度、省钱金额、本月最常孵出的精灵、连续记账天数。
- 卡片要能发朋友圈/小红书：竖版卡片、可下载图片（或复制分享文案），首屏展示，不是表格截图。
- 文案只写自己的真实数，不写无法验证的“超过 X% 大学生”。
- 月预算按 v2 口径用“周预算 × 4”估算，不单独设置。

### 3.5 许愿池（已完成，保留验收口径）

- 大额支出先进入许愿池冷静 24 小时，倒计时显示，24 小时后仍想买再确认记账，可随时取消。
- 当前实现：用户手动标记“计划购买”进入许愿池；≥100 元在确认时生成 Boss。
- 待补：v2 要求的“≥100 元默认自动进池，可关闭开关”，归到基础功能迁移，不放在 Phase 2。

## 4. 不做

银行同步、真实支付、复杂报表、AI 聊天助手。不做真实多用户同步，宿舍岛是单浏览器模拟 4 人。

## 5. 验收标准

- [ ] 底部“宿舍岛”Tab 可进入，首屏是合建岛 + 谁欠谁，不是表格。
- [ ] 记一笔共享账单后，AA 余额实时变；月底一键结算能清零并留痕。
- [ ] 投票能投、能出结果；岛规可编辑并保存刷新后仍在。
- [ ] 年报卡能生成、可下载/复制，含精灵数、亮度、省钱数三项。
- [ ] 画风与主岛一致，移动端可用；刷新后数据不丢；种子数字真实。
- [x] 许愿池：≥100 元可进池、24 小时倒计时、确认/取消可用（2026-11-19 已完成手动版本，自动阈值开关待补）。
