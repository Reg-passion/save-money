## 1. 一句话核心循环

记一笔账 → 生成一只怪物 → 怪物攻岛扣血 → 月底没超预算得一个蛋 → 蛋孵 3 天出精灵 → 精灵进图鉴、岛变亮

花钱有代价，省钱有奖励，怪物是敌人，精灵是守卫，蛋是月末的盼头，稀有概率是目标的杠杆。

## 2. 开岛设定（30 秒内完成）

- 月预算：默认 1500 元，可改
- 本月存钱目标：默认 300 元（约为预算的 20%），可改
- 岛名：默认“钱钱岛”，可改
- 初始精灵：选 1 只，图鉴从 1/32 开始；真实用户从 0/空岛开始，评委种子数据 18/32 仅用于演示
- 日均预算 = 月预算 / 当月天数，1500 / 30 = 50 元/天，作为配速锚

不设 8 个分类预算。分类超支只在后台提示，不在开岛时逼用户填表。

## 3. 岛血量（HP）

- 岛血量满值 100 点，1 点 = 15 元
- 扣血公式：扣血 = 四舍五入（单笔金额 / 15）
- 18 元奶茶扣 1 点，23 元外卖扣 2 点，46 元拼单扣 3 点，128 元火锅扣 9 点，300 元大件扣 20 点
- 钱数本身不变：论坛与界面同时显示“本月已花 X / 1500 元”和“岛血量 Y / 100”，血条只是可视化，不造假
- 血量状态：>50 晴，30-50 多云，10-30 阴，<10 危急；超预算血量归零，岛进入修补模式，下个月重新开岛，图鉴不清零

## 4. 怪物表（花钱生成怪物）

8 个分类，每类对应一种怪物家族，共 32 只精灵对应 32 种怪物/精灵形态（普通 18、稀有 10、隐藏 4）。

| 分类 | 小怪（普通） | 大怪（稀有） | Boss / 隐藏 |
|---|---|---|---|
| 外卖 | 外卖小怪 | 干饭人 | 深夜干饭兽 |
| 奶茶 | 奶茶小怪 | 珍珠圆圆 | 奶茶大王（进化） |
| 夜宵 | 夜宵小怪 | 夜宵兽 | 夜宵兽王 |
| 快递 | 快递箱小怪 | 拆箱怪 | 剁手大王 |
| 交通 | 小电驴 | 赶路兽 | 末班车守护 |
| 学习 | 书本怪 | 论文兽 | 考前突击兽 |
| 日用 | 纸巾怪 | 囤货兽 | 宿舍百宝兽 |
| 娱乐 | 游戏小怪 | 开黑兽 | 熬夜冠军 |

判定顺序（按顺序走，先命中先出）：
1. 隐藏款：备注关键词 + 金额/时间都对上，直接出隐藏款。例：18 元奶茶 + “三分糖”→ 珍珠圆圆；23 点后夜宵 + “螺蛳粉”→ 夜宵兽王。图鉴里只给谜语式提示，不直接写条件。
2. 分类首见：该分类第一次记账，必出该分类的一只新精灵（普通款）。保证评委 90 秒试玩一定有新东西。
3. 金额档：<10 元普通，10-30 元有概率稀有，30-100 元稀有概率提高，≥100 元不直接生成，先进许愿池冷静 24 小时，确认后才生成 Boss。
4. 重复/进化：同一只精灵（同一怪物）出现 3 次，第 3 次进化。例：奶茶精 ×3 → 珍珠圆圆 → 再 ×3 → 奶茶大王。重复不是浪费，是升级材料。
5. 兜底随机：以上都没命中，在该分类普通池里按交易 ID 做种子随机，保证同一天同类不连出两只一样的；一个分类记满 5 笔，一定集齐该分类普通款（保底）。

怪物动画：记完账 3 秒内播一段——怪物从屏幕边走过来，岛上精灵打它一下，血条掉下来。不是实时塔防操作，不做瞄准、放塔、走位。

## 5. 防守规则（不碰真钱）

- 精灵不改变金钱结算：同类精灵在场，怪物伤害的视觉效果减半，但实际扣血仍按金额算。
- 精灵的真正作用：收集数量计入图鉴里程碑，间接体现在蛋的展示与年报上，不直接改 HP。
- 防刷：每天召唤/生成上限 5 只，超过的只加岛屿能量，不再出新精灵。
- 省钱防守：每天花得比日均 50 元少，当晚结算出“省钱精灵”（存钱罐精、自律小岛民）；连续 3 天不超预算岛上长一棵树，7 天小屋亮灯，14 天解锁新区域，30 天解锁灯塔。断一天不清零，只是那天不长树。

## 6. 月底蛋与孵化

结算条件只看血量/省钱：
- 血量 > 0（没超预算）→ 得 1 个蛋
- 血量 = 0 或超预算 → 没蛋，下个月重新开岛，图鉴不清零

蛋分三档，按省下的钱定：
- 省 0-100 元 → 普通蛋
- 省 100-300 元 → 银蛋
- 省 300 元以上 → 金蛋

孵化：蛋需 3 天孵化，每天记一笔蛋裂一点，3 天后孵出精灵。演示时提供“演示孵化”快进按钮，正式使用按 3 天计。

## 7. 稀有概率公式（已锁定）

稀有概率 = 蛋的基础概率 + 多存部分 / 目标 × 30%，上限 +40%，总封顶 70%

- 蛋基础概率：普通蛋 10%，银蛋 25%，金蛋 40%
- 多存部分 = 实际省下 - 存钱目标；若 ≤0，则加成为 0
- 示例：目标存 300，实际省 420，多存 120，120 / 300 × 30% = 12%，普通蛋 10% + 12% = 22%
- 示例：目标存 300，实际省 600，多存 300，300 / 300 × 30% = 30%，普通蛋 10% + 30% = 40%
- 金蛋 + 满额加成可到 70%，封顶 70%

已知漏洞（写进论坛帖“反思与不足”，不藏着）：目标定得太低（如只定存 50 元）会很容易加满。后续应按上月实际建议目标，不能随便定。

## 8. 奖励分层（都不是真钱）

- 即时：召唤/怪物动画 + 血条变化 + 图鉴 +1
- 中期：收集里程碑——8 只“岛民”、16 只“守岛人”、24 只“大收藏家”、32 只“传说岛主”，每个称号岛上多一个装饰；进化精灵变大、改名
- 月末：蛋 + 孵化精灵 + 年报分享卡（精灵 x/32、岛亮度、省了多少钱、最常召唤的精灵、连续记账天数），竖版卡可下载/复制，不写无法验证的“超过 X% 大学生”

## 9. 手动导入（演示版数据来源）

- 手动单笔：金额、分类、备注、时间（默认现在），10 秒完成
- 批量导入 CSV：支付宝/微信导出账单文件上传，解析金额、分类、时间，先预览再确认导入。不要碰账号密码，不要调任何支付 API。
- 批量召唤：导入 20 笔不弹 20 个动画，一次“开包”最多弹出 5 只新精灵，其余转岛屿能量
- 不做实时同步：支付宝未开放个人账单接口；不做爬取、代登录、短信/无障碍抓取。数据只存浏览器本地（路线 B localStorage），不上传服务器

## 10. 一个月走通示例（验收用例）

小林，预算 1500，目标存 300：
- 11 月花 1180 元，怪物共扣 79 点血（1180 / 15 ≈ 79），岛还剩 21 点
- 没超预算，得 1 个金蛋（省 320 元，>300 元档）
- 多存 20 元，稀有加成 20 / 300 × 30% = 2%，金蛋 40% + 2% = 42%
- 蛋孵 3 天，孵出稀有奶茶精，图鉴 13/32，年报卡写“11 月守住了岛，省了 320 元，孵出稀有精灵”

超支示例：花 1620 元，超 120 元，血量归零，月底没蛋，下个月重新开岛，图鉴不清零。

## 11. 数据模型（路线 B，localStorage）

- transactions[]：金额、分类、备注、时间、怪物 ID、扣血
- spirits{}：32 只收集状态、进化次数、碎片数
- island{}：血量、亮度、树、区域、称号
- streak{}：连续天数、最后记账日
- eggs[]：蛋档位、获得日、孵化进度、是否已孵
- budget{}：月预算、存钱目标、日均预算
- 每次记账或打开时跑一遍检查：新怪物、新里程碑、到期许愿、超预算、月底结算。无服务端定时任务。

## 12. 不做

银行同步、真实支付、复杂报表、AI 聊天助手、实时塔防操作、排行榜按谁花得最少排名。

- [] 稀有概率按公式算，普通/银/金蛋基础 10%/25%/40%，加成上限 +40%，总封顶 70%
- [] 超支没蛋，下月重开，图鉴不清零
- [] 批量导入 CSV 一次最多弹出 5 只新精灵
