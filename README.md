## 核心循环（v2）

设日预算 + 周预算 → 正常记账（3 秒）→ 点“生成今日总结”看日报，蛋变好一点 → 7 天为一个孵化期，点“生成周总结”看周报 → 蛋品质升级 → 蛋孵出精灵 → 可选：用精灵打一场塔防小游戏，或跳过塔防直接开始下周

- 记账：花钱，不扣血、不被骂。花钱只决定怪物长什么样。
- 省钱：每天不超预算，蛋就变好一点。
- 总结：日报和周报由用户主动点击生成，不自动弹窗。
- 孵化：7 天一到，蛋裂开，出精灵。
- 塔防：可选。精灵是塔，怪物是你花出去的钱；打赢有奖励，打输不删档，跳过没有惩罚，只没有奖励。

三条原则不变：

1. 记账本先做轻，记账 3 秒完成。
2. 游戏是奖励，不是任务。
3. 超支不惩罚，只是不加分。

## 预算（开局只设两个数）

- 日预算：默认 50 元，可改
- 周预算：默认 350 元，可改；默认等于日预算 × 7，改日预算时自动跟着变
- 月预算：不单独设，按“周预算 × 4 = 1400 元”只在年报里做约数展示
- 存钱目标：不再设置。旧版 300 元目标废弃，改成蛋品质分
- 不设岛名、不设分类预算

## 每日反馈

每天 23:59 结算，或第二天第一次打开时结算。结算卡只显示 3 行：今天花了多少 / 省了多少 / 蛋加了几分。

| 今天情况 | 蛋 +分 | 文案 |
|---|---|---|
| 花销 ≤ 日预算 × 80%（≤40 元） | +15 | 完美的一天，蛋暖暖的 |
| 花销 ≤ 日预算（≤50 元） | +10 | 守住了，蛋亮了一点 |
| 花销 > 日预算 | +0 | 没关系，蛋还是昨天的样子 |
| 当天没记账 | +0 | 今天没记账，蛋没变化 |

不扣分、不倒退、不清零。超支只是今天不加分，明天还可以继续加。

### 日报（用户点击生成）

入口是“生成今日总结”，当天任何时候都能点，重复点更新同一份。必须包含：

- 今天花了 X 元 / 日预算 50 元，还剩 / 超了 Y 元
- 分类 Top 3，带占比条
- 今天最贵的一笔：金额、分类、时间
- 今天省了 Y 元（超支写 0，不写负数）
- 蛋 +N 分，当前总分，离下一档差多少
- 一句话建议，只给一条，不说教

生成后播放一次 ≤2 秒的蛋品质升级动画，可跳过。

### 周报（先报告，再升级，再孵化）

周日晚上或周一第一次打开时出现“生成周总结”按钮，流程固定 3 步：

1. 先出周报：本周花了 X / 350 元、7 天柱状图、分类占比、守住预算天数、最贵一笔、本周省了多少、一条下周建议。
2. 再播蛋品质升级动画（≤3 秒，可跳过）。
3. 最后孵蛋，蛋壳裂 3 下，出 1 只精灵，进图鉴。

周报要能保存、分享、导出图片或复制文案；文案只写自己的真实数，不写“超过 X% 大学生”。

## 蛋与 7 天孵化期

- 一个孵化期 = 7 天，默认自然周一到周日
- 每期开始出现 1 个新蛋，0 分
- 每天按上面的规则加分，每周不超预算额外 +10 分，满分 115 分

| 总分 | 蛋档位 | 稀有概率 |
|---|---|---|
| 0-29 分 | 普通蛋 | 10% |
| 30-69 分 | 银蛋 | 25% |
| 70-115 分 | 金蛋 | 40% |

- 演示时提供“演示孵化”按钮，正式使用按 7 天计
- 周报是基础功能，即使跳过塔防也必须完整

## 精灵图鉴（32 只）

- 普通 18、稀有 10、隐藏 4
- 来源：①平时记账按判定出新精灵，每天上限 5 只；②每周蛋孵出的 1 只
- 判定顺序不变：隐藏款 → 分类首见 → 金额档 → 重复 3 次进化 → 兜底随机 + 保底
- 塔防属性：普通攻击 1、稀有 2、隐藏 3；隐藏射程 3 格，其余 2 格
- 同类精灵打同类怪物伤害翻倍；精灵不改变金钱结算，只影响塔防

## 塔防小游戏（每周一次，可跳过）

- 每周蛋孵出精灵后解锁，入口在岛上写“本周怪物来了”
- 不打不扣分，下周一自动过期；点“跳过塔防，直接开始下周”没有奖励，也没有惩罚
- 每笔账单 = 一只怪物，按周一到周三 / 周四到周五 / 周六到周日分 3 波
- 怪物血量 = 四舍五入（金额 / 15）：18 元 = 1 血，128 元 = 9 血，300 元 = 20 血
- 分类决定怪物类型和速度；每波最多 10 只，超出合并成一只大怪
- 地图是一条弯曲小路 + 6-8 个放置格；点格子放精灵，自动攻击，不拖拽
- 岛血 100；怪物走到中心按剩余血量扣血；打完 3 波且岛血 > 0 为胜利
- 胜利奖励：1 颗种子 + 下周蛋 +10 分起步；失败无奖励，但图鉴、账单都不清零
- 目标一局 3-5 分钟，提供 1 倍 / 2 倍速和暂停

## 家园与种地（可选）

- 塔防胜利得到的种子，种在岛边 3 块地里
- 每天记一笔 = 浇一次水，3 天成熟，收获护盾叶（下周岛血 +10）、化肥（下周蛋 +10 分）或灯笼（下周隐藏概率高一点）
- 不种不影响记账和孵蛋

## 基础功能优先（v2 §11）

开发顺序必须是：记账 → 分类统计 → 日报 → 周报 → 蛋 → 塔防。塔防没做完，前面 4 项也必须能独立跑通。

基础功能清单（缺一项不算完成）：

- 记账：3 秒一键记，常用模板，改、删一笔，刷新后不丢
- 分类统计：8 个分类（外卖 / 奶茶 / 夜宵 / 快递 / 交通 / 学习 / 日用 / 娱乐），日 / 周 / 月都能看占比和总额
- 日报：点“生成今日总结”出一份
- 周报：点“生成周总结”出一份，可下载 / 复制
- 导出：账单可导出 CSV，数据可导出 JSON 备份、导入恢复
- 搜索 / 筛选：按分类、按金额、按时间筛选账单

## v2 实施指南落地说明

[`docs/code-implementation-guide-v2.md`](docs/code-implementation-guide-v2.md) 是下一阶段的代码实施指南，不是“推倒重写”的命令。落地时按下面几条执行：

- **逻辑层先拆纯函数**：记账、预算、蛋、日报周报、召唤、怪物、塔防都放 `src/lib/*.ts`，组件只读 state、调函数、显示结果；先迁移现有逻辑，不先动 UI。
- **不从零重建**：许愿池、JSON 备份、月结蛋与 3D 岛都是已在跑的功能；按模块替换，保留已完成能力，迁移期间旧数据要能读。
- **3D 与 2.5D 不冲突**：指南建议新项目用 2.5D SVG 岛、3D 可选；当前仓库已有 three.js 3D 岛，暂时保留为视觉层。v2 新功能（日报周报、蛋、塔防）优先用 DOM / SVG / CSS，不引入新的重型依赖；塔防按指南用 DOM + `requestAnimationFrame`，不用 Three.js 或游戏引擎。
- **存储按指南收敛**：目标是把多键 `money-island:*` 迁到单键 `money-island:v1` 的 `IslandState`；先做兼容读取和迁移，确认旧账单、图鉴、蛋不丢后再切换写入，迁移完成前不删旧键。
- **部署沿用现有 CI**：指南示例把 `base` 写死为 `/save-money/`；本仓库已用 `BASE_PATH` + GitHub Actions，保留现有做法，本地和线上共用一套配置。
- **按顺序做**：types/storage/ledger → budget/report → egg/summon → monster/tower → island/farm；塔防没做完，前面四项也必须能独立跑通（v2 §11）。

### 指南与当前实现的关键差异

| 主题 | 指南写法 | 本项目处理 |
|---|---|---|
| 金额单位 | `amount` 用元，`Math.round(x * 100) / 100` | 现有代码统一用整数分 `amountCents`；迁移保留整数分，只在显示层转元，避免浮点误差 |
| 无记账日 | 示例 `dailyScore(0, budget)` 返回 +15 | v2 规格要求“没记账 +0”；`settleDay` 必须先判断当天有无账单，再算分 |
| 分类 | 中文 `Category` 字符串 | 现有 `CategoryId` 为英文；先定映射再迁存储，不直接改旧账单 |
| 存储 | 单键 `money-island:v1` | 现有多键 `money-island:*`；按“兼容读 → 迁移 → 切写”推进 |
| 每日召唤 | 注释要求每天上限 5 只，示例未实现 | 迁移时在 `pickSummon` 前判断，超过上限只加能量 |
| 周加分 | 规格要求每周不超预算 +10，指南示例未实现 | 在周结算/周报流程补上，满分 115 |
| 3D 岛 | 建议 2.5D SVG，3D 可选 | 现有 3D 岛保留为视觉层；塔防用 DOM + `requestAnimationFrame` |
| 演示数据 | 演示结果不能写正式图鉴 | 现有 `demo-eggs` / `demo-settlements` 已分开，继续保持 |
| 部署 | `base` 写死 `/save-money/` | 现有 `BASE_PATH` + GitHub Actions，保留 |

## 技术栈（暂不变）

- Vite 8 + React 19 + TypeScript 7 + Tailwind CSS 4
- three.js 0.187（3D 岛屿，程序化几何体）；精灵与图鉴为内联 SVG
- v2 新功能按指南优先 DOM / SVG / CSS：塔防用 DOM + `requestAnimationFrame`，不引入 Three.js、Canvas 游戏引擎或重型动画库
- Vitest 5（规则、备份、3D 工具单测）
- 纯前端单页应用，无后端、无数据库、无登录
- 数据只存在浏览器 localStorage，不上传服务器
- 部署：GitHub Pages + GitHub Actions，CI 使用 Node 24

## 数据与隐私

- 现有代码使用 `money-island:` 前缀的多键存储：`settings`、`bills`、`summon`、`eggs`、`settlements`、`wishes`、`demo-eggs`、`demo-settlements`
- v2 规格与指南要求最终合并为 `money-island:v1` 下的 transactions / spirits / egg / budgets / tower / farm；交易额外存 `date`、`monsterHp`，每日分数用 `dailyScores[date]` 防重复结算。迁移未做，迁移时不要覆盖旧数据；目标模型见指南 §2
- 不做实时同步：支付宝未开放个人账单接口；不做爬取、代登录、短信 / 无障碍抓取
- 换浏览器或清理数据前先导出 JSON 备份
