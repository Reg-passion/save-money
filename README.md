## 核心循环（已锁定）

记一笔账 → 生成一只怪物 → 怪物攻岛扣血 → 月底没超预算得一个蛋 → 蛋孵 3 天出精灵 → 精灵进图鉴、岛变亮

- 岛血量 100 点，1 点 = 15 元，扣血 = 四舍五入（金额 / 15）
- 月预算默认 1500 元，存钱目标默认 300 元，日均预算 50 元
- 蛋分三档：省 0-100 元普通蛋，100-300 元银蛋，>300 元金蛋
- 稀有概率 = 蛋基础概率 + 多存部分 / 目标 × 30%，上限 +40%，总封顶 70%
- 基础：普通蛋 10%、银蛋 25%、金蛋 40%
- 精灵不改变金钱结算，只影响视觉与收集
- 每天召唤上限 5 只；≥100 元先进许愿池冷静 24 小时

详细规则见 `tower-defense-spec.md`，数字以该文件为准，不要让 Qoder 自己编数字。

## 技术栈（路线 B，已定）

- Vite + React + TypeScript + Tailwind CSS
- 纯前端单页应用，无后端、无数据库、无登录
- 数据只存在浏览器 localStorage，键名前缀 `money-island:`，刷新后还在，换浏览器重新开岛
- 画风：扁平 SVG 精灵与岛屿，统一配色，内联 SVG，不依赖外部图片
- 部署：Qoder Sites，Anyone can access

## 怎么指挥 Qoder（先读文档，再粘提示词）

1. 在 Qoder 里打开 `save-money` 文件夹，先放进这 4 个文件：
- `README.md`（本文件）
- `tower-defense-spec.md`
- `DATA-PLAN.md`
- `phase-2-dorm-aa-report-spec.md`
2. 第一句话让 Qoder 先读这 4 个文件，复述核心循环和验收标准，不要先写代码。
3. 按 `qoder-prompts.md` 里的 Prompt 0-6 顺序粘，一个一个做：
- Prompt 0：搭架子
- Prompt 1：岛屿 + 血量 + 记一笔
- Prompt 2：怪物生成 + 图鉴
- Prompt 3：蛋 + 稀有概率 + 孵化
- Prompt 4：手动导入 CSV + 种子数据
- Prompt 5：宿舍岛 + AA + 投票 + 年报（Phase 2，等 MVP 跑通再做）
- Prompt 6：部署 + 验收
4. 每个 Prompt 跑完都要打开预览，照验收清单点一遍，通过了再粘下一个。

提示词全文在 `qoder-prompts.md` 里，操作手册在 `qoder-implementation-guide.md` 里。

## 数据来源（演示版，合规）

- 手动记账：金额、分类、备注、时间，10 秒完成
- 批量导入 CSV：用户在支付宝 / 微信导出账单文件，上传解析，先预览再确认，一次最多弹出 5 只新精灵
- 不做实时同步：支付宝未开放个人账单接口；不做爬取、代登录、短信 / 无障碍抓取
- 本地存储、不上传服务器，本身就是隐私优势

长期完整版最现实的口子是校园一卡通合作，其次是支付宝小程序 / 开放平台企业合作，写进论坛帖“未来规划”里，不要写成“已实现”。
